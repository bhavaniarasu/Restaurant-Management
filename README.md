# Restaurant Management System

## Project Description
This is a simple Restaurant Management System developed using C++.

The system allows users to:
- Enter customer details
- Book a table
- Order food
- Generate a bill
- Make payment
- Store customer and booking details in a file

## Technologies Used
- C++
- Object-Oriented Programming
- File Handling
- Exception Handling

## OOP Concepts Used
- Class and Object
- Constructor
- Single Inheritance
- Functions

## Features
- Table availability checking
- Table booking
- Food ordering
- Bill calculation
- Payment validation
- Customer record storage
- Exception handling
